# Passo 5: Configuração do Arquivo ``models/user_models.py``

O objetivo do arquivo ``models/user_models.py`` é:

**1. Definir o modelo do usuário:**

- Representar a tabela de usuários no banco de dados utilizando SQLAlchemy.

**2. Manter a aplicação organizada:**

- Centralizar todas as definições de tabelas em um único lugar, separando a lógica dos modelos do restante da aplicação.

**3. Garantir boas práticas:**

- Usar ORM para evitar escrever consultas SQL diretamente, tornando o código mais legível e seguro.

---

## Explicação do Código ``models/user_models.py``

---
**1. Importações:**

``from sqlalchemy import Column, Integer, String:``

- Importamos as classes necessárias para definir as colunas do modelo.
- ``Column`` é usada para declarar cada campo da tabela, como Integer e String.

``from sqlalchemy.ext.declarative import declarative_base:``

- ``declarative_base`` é usado para criar uma classe base que será compartilhada por todos os modelos.
- Ele permite que o SQLAlchemy saiba como mapear os modelos para as tabelas no banco de dados.

``Base:``

- É a classe base herdada por todos os modelos SQLAlchemy.
- Ela é configurada no arquivo ``database.py`` e conecta os modelos ao banco de dados.

~~~python
from sqlalchemy import Column, Integer, String
from sqlalchemy.ext.declarative import declarative_base
from app.database import Base
~~~

---
**2. Definição da Base:**

``Base = declarative_base():``

- Criamos uma instância da classe base ``declarative_base``, que será usada como a classe pai para todos os modelos.

- Isso informa ao SQLAlchemy que todos os modelos definidos com essa base são mapeáveis para tabelas no banco de dados.

~~~python
Base = declarative_base()
~~~

---
**3. Definição do Modelo de Usuário:**

``class User(Base):``

- A classe ``User`` representa a tabela de usuários no banco de dados.

- O nome da tabela é definido pela variável ``__tablename__``, e as colunas são declaradas como atributos da classe.

~~~python
class User(Base):
    """
    Modelo de Usuário representando a tabela 'users' no banco de dados.
    """
    __tablename__ = "users"
~~~

---
**4. Definição das Colunas:**

``id:`` Representa a coluna primária da tabela.

- ``primary_key=True:``
  - Indica que esta coluna é a chave primária.

- ``index=True:``
  - Cria um índice para melhorar o desempenho nas buscas.

- ``autoincrement=True:``
  - Garante que o valor será incrementado automaticamente.

``username:`` Armazena o nome de usuário.

- ``unique=True:``
  - Garante que não haverá dois usuários com o mesmo nome.

- ``nullable=False:``
  - Torna o campo obrigatório.

- ``index=True:``
  - Cria um índice para acelerar as buscas por nome de usuário.

``hashed_password:`` Armazena a senha criptografada do usuário.

- ``nullable=False:``
  - Torna o campo obrigatório.

~~~python
    id = Column(Integer, primary_key=True, index=True, autoincrement=True)
    username = Column(String, unique=True, nullable=False, index=True)
    hashed_password = Column(String, nullable=False)
~~~

---

## Estrutura no Banco de Dados

Se estivermos usando **PostgreSQL**, o modelo acima criará uma tabela chamada ``users`` com a seguinte estrutura:

|Nome da Coluna|Tipo|Restriçõe|
|-|-|-|
|id|Integer|PK, Auto Increment|
|username|String|Único, Não Nulo|
|hashed_password|String|Não Nulo|

O modelo será usado em:

- **Autenticação:** Para validar as credenciais do usuário.
