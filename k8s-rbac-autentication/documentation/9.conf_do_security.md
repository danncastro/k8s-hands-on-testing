# Passo 8: Configuração do Arquivo ``utils/security.py``

Este arquivo será usado para implementar funções relacionadas à segurança da aplicação, como:

- Criptografar senhas antes de armazená-las no banco de dados.
- Verificar se uma senha fornecida corresponde ao hash armazenado.
- Facilitar futuras implementações relacionadas à autenticação, como geração de tokens.

---

## Explicação do Código ``utils/security.py``

---
**1. Importações:**

``CryptContext:``

- É uma ferramenta fornecida pelo ``passlib`` para gerenciar diferentes esquemas de hashing de senhas.

**Por que usar o bcrypt?**

- Seguro contra ataques de força bruta.
- Implementa salting automaticamente (um dado adicional para tornar hashes únicos).
- Amplamente adotado e reconhecido na indústria.

~~~python
from passlib.context import CryptContext
~~~

---
**2. Configuração do Contexto de Criptografia:**

``schemes=["bcrypt"]:``

- Define o algoritmo de hashing que será utilizado.

``deprecated="auto":``

- Atualiza automaticamente hashes antigos para o esquema atual, se necessário.

~~~python
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
~~~

---
**3. Função get_password_hash:**

``def get_password_hash(password: str) -> str:``

- Esta função transforma uma senha em texto puro em um hash criptografado.

``pwd_context.hash:``

- Cria um hash seguro usando o algoritmo configurado no contexto (``bcrypt``).

~~~python
def get_password_hash(password: str) -> str:
    """
    Gera um hash seguro para a senha fornecida.
    :param password: Senha em texto puro.
    :return: Hash criptografada da senha.
    """
    return pwd_context.hash(password)
~~~

---
**4. Função verify_password:**

``def verify_password(plain_password: str, hashed_password: str) -> bool:``

- Esta função verifica se a senha fornecida pelo usuário é válida, comparando-a com o hash armazenado.

``return pwd_context.verify(plain_password, hashed_password)``

- Compara a senha em texto puro com o hash armazenado e retorna True ou False.

~~~python
def verify_password(plain_password: str, hashed_password: str) -> bool:
    """
    Verifica se uma senha em texto puro corresponde ao hash armazenado.
    :param plain_password: Senha em texto puro fornecido pelo usuário.
    :param hashed_password: Hash armazenada da senha.
    :return: True se as senhas coincidem, False caso contrário.
    """
    return pwd_context.verify(plain_password, hashed_password)
~~~

---
**5. Segurança e Boas Práticas:**

**Por que não armazenar senhas em texto puro?**

- Em caso de vazamento de dados, todas as contas ficariam comprometidas.
- O hashing garante que as senhas não sejam legíveis, mesmo que os dados sejam expostos.

**Uso do Salting:**

- O algoritmo bcrypt adiciona automaticamente um salt a cada senha, tornando hashes únicos, mesmo para senhas iguais.
  
**Evitar Funções Caseiras:**

- Usar bibliotecas amplamente testadas, como o ``passlib``, reduz o risco de vulnerabilidades.
