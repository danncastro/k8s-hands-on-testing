# Passo 7: Configuração do Arquivo ``routers/auth.py``

O objetivo do arquivo routers/auth.py é:

**1. Criar rotas para manipulação de usuários:**

- Permitir que a API valide a existência de um usuário e adicione novos usuários.

**2. Implementar boas práticas de autenticação:**

- Usar senhas hash (criptografadas) para armazenamento seguro.

**3. Garantir separação de responsabilidades:**

- Centralizar as rotas de autenticação em um único arquivo para facilitar a manutenção

---

## Explicação do Código ``routers/auth.py``

---
**1. Importações:**

``from fastapi import APIRouter, Depends, HTTPException, status:``

- ``APIRouter:``
  - Permite criar rotas agrupadas e modularizadas, ajudando na organização do código.
- ``Depends:``
  - Usado para declarar dependências, como a conexão com o banco de dados.
- ``HTTPException:`` Permite lançar erros HTTP personalizados, como 401 (não autorizado) ou 400 (solicitação inválida).
- ``status:``
  - Fornece constantes para os códigos de status HTTP, como ``status.HTTP_400_BAD_REQUEST``.

``from sqlalchemy.ext.asyncio import AsyncSession:``

- ``AsyncSession:`` Fornece acesso assíncrono ao banco de dados.

``from sqlalchemy.future import select:``

- ``select:`` Um construtor de consultas para buscar dados no banco.

``from app.database import get_db:``

- Dependência que fornece uma sessão do banco de dados para cada requisição.

``from app.models.user_models import User:``

- Modelo ORM usado para realizar operações no banco de dados.

``from app.schemas.dataset import UserCreate, UserResponse:``

- ``UserCreate:`` Esquema para validar os dados recebidos ao criar um usuário
- ``UserResponse:`` Esquema para formatar a resposta ao cliente.

``from app.utils.security import get_password_hash, verify_password:``

- ``get_password_hash:`` Função para criptografar a senha do usuário antes de armazená-la.
- ``verify_password:`` Função para comparar uma senha em texto com seu hash..

~~~python

from app.schemas.dataset import UserCreate, UserResponse
~~~

**2. Criação do APIRouter:**

``router = APIRouter(prefix="/auth", tags=["Auth"]):``

- ``prefix:`` Adiciona ``/auth`` automaticamente a todas as rotas definidas neste arquivo.
  - Todas as rotas definidas neste arquivo terão o prefixo ``/auth`` (ex.: ``/auth/register``).
- ``tags:`` Categoriza as rotas no Swagger (documentação gerada pelo FastAPI).

~~~python
router = APIRouter(
    prefix="/auth",
    tags=["Auth"]
)
~~~

---
**3. Rota de Registro de Usuário:**

``@router.post("/register", response_model=UserResponse):``

- ``@router.post:``
  - Declara uma rota HTTP POST no endpoint ``/auth/register``.

- ``response_model=UserResponse:``
  - Garante que a resposta siga o esquema ``UserResponse``, ocultando campos como a senha.

``query = select(User).where(User.username == user.username)``

- ``select:`` Consulta o banco para verificar se o username já existe.

``existing_user = result.scalar_one_or_none()``

- Retorna um único resultado ou **None** se o usuário não for encontrado.

``hashed_password = get_password_hash(user.password)``

- Criptografa a senha usando o utilitário definido em ``utils/security.py``.

``new_user = User(username=user.username, hashed_password=hashed_password)``

- Cria uma nova instância do modelo User com os dados fornecidos.

**Lógica do registro:**

- Busca no banco para verificar se o usuário já existe.
- Gera um hash da senha com ``get_password_hash``.
- Cria um novo objeto ``User`` e o adiciona ao banco.

~~~python
@router.post("/register", response_model=UserResponse)
async def register_user(user: UserCreate, db: AsyncSession = Depends(get_db)):
    """
    Rota para registrar um novo usuário.
    """
    # Busca no banco de dados para verificar se o usuário já existe.
    query = select(User).where(User.username == user.username)
    result = await db.execute(query)
    existing_user = result.scalar_one_or_none()

    # Se o usuário já existe, lançamos uma exceção.
    if existing_user:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="Username already exists",
        )
~~~

**3. Segurança e Melhorias:**

**Hash de senhas:**
